## 独立测试结论

预注册主总体为 same 条件，六项主结果共同做 Holm 校正。两项实验各方法的首次成功率均为 0。H1 的完整报告相对 S+P 报告，家族等权复发率差为 -0.0949，95% CI [-0.2361, 0.0440]，Holm p=1；H4 的 matched 相对 cycle 为 -0.0139，95% CI [-0.1134, 0.0880]，Holm p=1，相对 random 为 -0.0324，95% CI [-0.1227, 0.0509]，Holm p=1。因此 H1、H4 及 H4 验证对照均未得到本次确认支持。结果不证明方法等效，因为协议没有非劣效界限。

预先保留的 transfer 条件呈现边界信号：E1 完整报告相对 S+P 的复发率差为 -0.2130，95% CI [-0.2894, -0.1366]，该实验完整注册比较族 Holm p=0.0098；E3 matched 相对 cycle/random 的差值方向也为负，但 Holm p 分别为 0.1094 和 0.375，不能作为 H4 的确认性支持。这个条件差异可作为后续论文的边界发现，不能回填修改 same 主总体。

按研究计划的阶段门槛，核心 M1 在冻结主总体上没有形成 H1/H4 信号，因此不再投入 14B/27B、学习式分配、长序列或外部有效性扩展。当前结果已足以回答预注册核心假设，并满足“全部实验完成或足以判断假设时停止”的条件。
