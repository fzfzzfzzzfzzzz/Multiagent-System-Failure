# 可执行协议 v1

## 主估计对象

H1：固定成功经验与预防规则后，失败证据是否改变新实例行为。主对照 E1 `components_SOCDKPU` 对 `components_SP`。

H4：同一冻结报告集合的投递映射是否影响行为。主对照 E3 `matched` 对 `cycle`，随机置换为复核；另输出二因素交互 `(Y11-Y10)-(Y01-Y00)`。

H3、H6 为次级问题。F5/F6、在线学习、异构团队为扩展。禁止将测试集最优子集当成可部署策略；学习式策略只用训练结果拟合。

## 环境与来源

四个决策角色：coordinator 可读全局资源约束并分配验收责任；provider 独占源记录读取及发布；analyst 拥有转换契约、计算及本地资源预订；executor 才能提交事务。消息按实际收件人路由，各角色只看到自身工具结果及收到的消息。

F1 转换错误；F2 异步受理误当确认；F3 消费旧版本；F4 局部合法资源分配违反联合约束；F5 缺少独立证据；F6 未完成责任分配与签署。评分器读取实际事件和状态，拒绝自报成功。F2/F3 的中间错误消费即使随后修复仍记复发。F4 的严格组合失败要求所有声明的局部检查通过。

源采集按预定种子运行正常 Agent，选择首个实际出现指定机制的失败。不能将未提交、其他错误或失败机制预测值替代真实检测结果。全部采集尝试、成功和未获得源失败的任务都留存。报告器只收到源公开轨迹与允许的源工具反馈，不接收机制真值或未来任务。

## 划分与控制

外层按不同聚合规则划分：8 个训练规则、6 个开发规则、12 个测试规则。所有规则通过合法契约公开公式。每规则覆盖六种机制及两个后端；后端共享规则，因此统计按规则家族跨机制/后端聚类。每个任务的数值、实例 ID、对象和角色绑定确定性生成。

Same 使用新数据；transfer 同时改角色绑定和常规执行顺序；renamed 单独只改角色绑定；reversal 修改契约；clean 去掉原错误机会；unrelated 是无原错误机会的相邻工作流控制，不等同于跨领域独立基准。

F2 反转为同步接口且禁止旧 receipt 轮询；F3 反转为固定版本，即使服务更新仍需使用原版本；F4 反转为最低联合服务量要求，旧的最小预订策略不再足够。F5/F6 反转取消旧检查要求。F1 反转没有独立机制含义，只可作为普通条件控制，不用于 H5 主结论。

## 报告

O 是工具观测的直接序列化；S 是实际局部检查通过的记录；C/D/K/P/U 来自同一报告器并始终标记为假设、条件、建议或不确定性。引用必须存在于源事件。引用存在只证明可追溯，不证明推断正确。V 默认缺失：没有真实独立验证的修复，就不能生成“已验证修复”。输出明确标记 `V_available`，空 V 的组不能支持修复信息增量结论。

删除组件只删冻结字段，不重新摘要。形式对照按两种格式的最大 token 成本共同选取原子事实，确保事实 ID 集合一致。置换在预算裁剪之后进行，检查报告多重集合哈希一致；视图不含显式“给某角色”的收件标签。

角色检索和 G-Memory 适配只使用相同可用证据。主成分/置换实验使用单一支持源；train-only 严格迁移使用训练经验库且不提供测试支持。独立反思额外从各角色自身事件和实际收到的消息生成，并单独记录生成成本。

## 预算与成本

E1 为内容完整性对照，采用较充足的团队初始报告额度 16,384 tokens；其目的不是严格等总成本。E2 每名接收者同额度 512，报告团队实际开销。E3 明确区分内容全集匹配和形式对照。E5 启动时报告额度为 512/1,024/2,048/4,096。

这些额度约束**首次投递上下文容量**。自回归 API 每次调用会重新 prefill 历史，实际重复阅读量另存 `report_read_tokens_actual`，全部进入 API `input_tokens`。它们不是整次运行累计 token 上限。效率结论必须依据最终的实际调用成本曲线，不能把初始报告容量叫作全系统预算。若论文必须主张累计计算预算内最优，需使用记录的实际总成本作匹配分析而不是直接按这四档排名。

不使用字数估算 token。真实模型必须有 tokenizer 端点和 API usage。生成、源采集、实际报告阅读、转发后的上下文、执行、网络重试分别保存；模型分项记录真实 usage。未知服务端计费记 `usage_unknown`，不会填零冒充精确计费。报告阅读已经包含在 execution input，汇总不能再把 report_tokens 加一次。

源采集与策略训练为共享成本，分别列出、按复用次数摊销；单次实际成本为报告生成加目标调用。无记忆/全历史不虚构摘要生成成本。学习器训练成本在策略元数据中单列。

## 评分与权限边界

模型只能输出 JSON 动作，无 shell、文件、网络自由工具。独立 worker 持有任务原始状态及评分器，逐角色白名单控制 API；报告器/模型从未获得 worker 的私有路径读取能力。可信 Python 调度器可在任务结束后读取隐藏结果用于统计。目录名本身不是安全边界；此边界依赖封闭工具 API 与进程通信。不可在当前威胁模型下为 Agent 增加任意执行代码工具。

支持源诊断采用白名单构造输入，禁止将保存的 `score` 整个对象传给报告器。目标隐藏评分不会写入记忆。离线策略训练可以使用训练集评分，测试评分只能进入分析输出。

## E6

L0 固定记忆与规则；L1 外部经历流增长、固定角色检索；L2 与 L1 字节一致的库、更新联合接收者策略；L3 自身经历、更新策略。在线奖励仅使用实际公开的 transport_committed 与工具错误率，是粗糙代理而非隐藏全局正确性。每阶段只读探针比较保留报告/移除报告/移除 K，验证前后状态哈希相同。

现有 E6 是训练时间流与开发只读探针的扩展实验，不得称为最终未见任务上的持续学习确认性结论。完整流保存快照；E6 遇到中断从新的输出目录重跑，静态 E0–E5/E7 支持逐运行续跑。

## 统计

主指标：首次提交成功、最终成功、固定机会分母上的任何同机制复发。未提交单列 abstention，不能因为不行动把样本移出分母。首次成功与最终成功不同；第一次错误提交后再次正确提交，只提升最终成功。

配对键为源元任务、目标实例与模型种子。按规则家族聚类，并等权平均家族差值；输出 cluster bootstrap 95% CI、块置换 p、Holm 调整。少于 10 个聚类时输出明确提示，不自动接受假设。各角色和多个种子不增加独立样本量。

默认非劣效界限不写死，也不自动宣称非劣效。正式运行前可基于开发结果在冻结协议中预注册实际效应门槛。研究没有结果时不能写显著提升、真实根因、广泛迁移或递归自我改进。
